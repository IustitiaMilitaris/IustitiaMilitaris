# Карта інтеграції та план масштабування

## Режими впровадження

| Середовище | Практичний сценарій | Реалізований канал | Що перевірити перед запуском |
|---|---|---|---|
| ВВНЗ | Самостійний розбір перед семінаром, потім дискусія з викладачем | Браузер, UKR/ENG, власний профіль або гостьовий доступ | Перевірку юридичного змісту, доступність матеріалів, правила ненормативного оцінювання |
| Курси підвищення кваліфікації МОУ/ЗСУ | Розбір кадрових рішень, конфлікту інтересів і постачання | Групова кімната, QR, WebSocket, режим проєктора | Довірену Wi-Fi мережу, доступність LAN-IP, пропускну здатність і брандмауер |
| Навчальний центр без інтернету | Заняття з власним локальним хостом | `npm run build` + `npm start`; телефони звертаються до LAN-IP | Наявність з’єднання з хостом, навіть без доступу до інтернету; живлення та резервну копію |
| Індивідуальна офлайн-підготовка | Повторне відкриття попередньо кешованого застосунку | PWA | Попереднє завантаження всіх чанків; HTTPS або localhost; API/статистика/акаунти без сервера недоступні |
| Moodle або інша SCORM-сумісна LMS | Самостійний кейс як навчальний пакет | Експорт SCORM 1.2 ZIP у браузері | Пробний імпорт, запуск і завершення у конкретній LMS |
| «Дія.Освіта» | Можливе розміщення пакета за правилами платформи | Наявний формат SCORM 1.2 | Підтвердження прийнятного формату та процедури публікації оператором; фактичне розміщення не підтверджене |

Пакет містить `imsmanifest.xml`, автономний `index.html` та `scorm-api.js`. Плеєр повідомляє LMS `cmi.core.lesson_status`: спочатку `incomplete`, після завершення `completed`. Відповіді, шкали й нотатки не передаються. LMS може сама знати особу слухача; симулятор не гарантує анонімності зовнішньої LMS.

## Контент без зміни програмного коду

Викладач відкриває `/builder`, створює шаблон або копію кейсу, редагує етапи, обирає норми, перевіряє досяжність і запускає попередній перегляд. JSON можна експортувати та передати команді супроводу. Імпорт сам собою не змінює сервер. Дія «Зберегти до каталогу» записує валідний S04–S99 у `server/data/custom-scenarios/`; «Створити групове заняття» спочатку зберігає, потім запускає кімнату. Увімкнення в репозиторій окремо потребує погодження змісту та `python3 zibraty.py`. Нові норми потребують окремої звірки джерел.

## Наступні кроки

1. Провести предметне й юридичне рев’ю трьох кейсів; підтвердити зв’язок із виданням CIDS.
2. Провести пілот у ВВНЗ: перевірити доступність, час підготовки та зрозумілість розбору без рейтингу учасників.
3. Перевірити SCORM у цільовій LMS та підготувати інструкцію для адміністратора курсу.
4. За потреби спроєктувати xAPI: узгодити LRS, мінімальні поля та правові підстави обробки даних. **xAPI наразі не реалізовано**, універсальний трекінг усіх виборів не є метою.
5. Для багатьох хостів замінити файлове сховище й локальні ліміти на узгоджену інфраструктуру з тим самим принципом мінімізації даних. Поточний MVP розрахований на один процес із одним каталогом даних.
