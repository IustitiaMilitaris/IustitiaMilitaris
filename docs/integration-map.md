# Інтеграція та розгортання

Локальний сервер слухає мережеві інтерфейси й віддає зібраний `dist/`. Для заняття пристрої мають бути в одній доступній LAN; ведучий показує QR. WebSocket синхронізує кімнату, таймер та голоси. Кімнати зберігаються в RAM і не переживають перезапуск сервера.

Динамічна перевірка LAN IP виконується кожні 5 секунд; таймер має `unref()` та очищення. `/api/server-info` обчислює адреси при кожному запиті. Публічні домени й localhost автоматично не перенаправляються. Якщо старе з’єднання вже втрачено до повідомлення, нову адресу може знадобитися відкрити вручну. Секрет ведучого не переноситься через URL.

PWA кешує клієнтські ресурси; перший запуск потребує завантаження. Service Worker доступний у захищеному контексті або на localhost; звичайний HTTP за LAN IP не гарантує PWA. Групова синхронізація й акаунти потребують сервера.

Експорт SCORM 1.2 створює ZIP для LMS і передає статус завершення без оцінки людини. xAPI та централізоване багатосерверне сховище не реалізовані. Для масштабування потрібні окремий проєкт сховища кімнат, резервування й перевірка навантаження. Один процес обслуговує один каталог DATA_DIR.
