# Архітектура

React + TypeScript + Tailwind CSS, збірка Vite; Node.js + Express + ws. Власна маршрутизація через History API у `src/App.tsx`, без React Router.

Браузер → компоненти `src/components/` → JSON-граф `stsenarii/`; сервер → кімнати WebSocket у пам’яті та файлове сховище профілів і користувацьких задач. Переклади UKR/ENG лежать у `src/i18n/`. `schema.json` і `zibraty.py` перевіряють структуру, досяжність і правові посилання.

Три захищені базові кейси — ЗАДАЧА 1–3. Конструктор зберігає ЗАДАЧІ 4+ у `server/data/custom-scenarios/` (або в `DATA_DIR/custom-scenarios/`), окремо — прев’ю в `images/`. Є перевірка JSON, запуск у групі, завантаження PNG/JPEG/WebP, видалення з підтвердженням назви та автоматична перенумерація користувацьких задач. Базові кейси не видаляються цим API.

Таймери «Без обмеження / 10 хв / 15 хв» працюють в обох режимах. У групі час запускається після відкриття першого етапу; завершення рекомендованого часу не закриває кімнату. «Тактичний трекер» показує час і три окремі шкали. Самостійний прогрес розділений за ключем `scenarioId::timerMode`; старі ключі читаються як `none`. Профіль рахує унікальні задачі.

Груповий SVG показує відсотки голосів; учасник після закриття голосування локально читає роз’яснення А–Г. Це не змінює гілку ведучого. Панель «5 перевірок CIDS» допомагає обміркувати рішення.

У базі 60 перевірених норм: 57 зі статусом `zvireno` і 3 — `zvireno-rekomendatsiinyi`. Статуси надано командою 20.11.2026. Дві постанови: ВП ВС № 9901/72/19 і ККС ВС № 335/10825/16. UI показує офіційні назви й номери актів: ЗУ № 1700-VII, ЗУ № 4742-IX, КЗпП, ККУ, Конституція та короткий пункт усередині бейджа.

Сервер оновлює LAN-адреси, повідомляє клієнтів про зміну IP; QR і посилання оновлюються. Автоперехід обмежено неактивним приватним IPv4 і тим самим портом з перевіркою доступності. Сесії та hostSecret між різними origin браузер не переносить.
