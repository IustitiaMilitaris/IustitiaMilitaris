# Зловживання та запобіжники

Не використовуйте результат для кадрового рейтингу чи встановлення вини. Три шкали не складаються в один бал; зворотний зв’язок оцінює рішення. Висновки визначені JSON, без LLM у runtime. «5 перевірок CIDS» — методична допомога, а не юридична експертиза.

Zero-PII означає відсутність вимоги вводити реальні ПІБ, звання чи частини. Гостьовий доступ збережено; локальні акаунти використовують вигадані псевдоніми. Не записуйте персональні або службові відомості у вільні поля. Сервер обробляє технічні IP для обмеження частоти запитів; адміністратор хоста має доступ до локального сховища.

Паролі захищені scrypt; сесії підписуються секретом. hostSecret перевіряється порівнянням сталої тривалості; операції ведучого недоступні учаснику. Є перевірка Origin/CSRF, rate limiting, CSP, обмеження розміру JSON і WebSocket-повідомлень, перевірка зображень та ізоляція службових файлів від статичної видачі.

Користувацькі задачі перевіряються перед записом; базові захищені. Видалення потребує підтвердження назви, але це не замінює резервних копій. Не публікуйте `.env`, серверні дані й секрети. Для недовіреної мережі потрібен HTTPS та налаштований доступ. Автотести не доводять юридичної правильності чи повної відсутності вразливостей.
