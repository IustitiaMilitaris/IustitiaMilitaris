# Артефакти процесу команди

Ця папка — індекс доказів еволюції рішення для пункту 5 Політики ШІ, а не твердження, що всі матеріали вже додані. Підтверджені в репозиторії джерела:

- Початковий PDF вилучено з поточної публічної версії на вимогу команди; історію адаптації збережено нижче. Видалення файла не очищує попередню історію Git.
- [cases-source-review.md](../cases-source-review.md) — редакційні рішення під час адаптації.
- [ai.md](../ai.md) — поточне розкриття застосування ШІ та меж перевірки.
- [security-hardening.md](../security-hardening.md) — історична технічна записка про захист, англійською.
- Історія Git — послідовність змін. Перегляд: `git log --oneline --all`; авторство комітів саме по собі не доводить юридичного рев’ю.

## Що долучити перед подачею

1. Початкові авторські чернетки із датою, коротким поясненням змін і дозволом на подання. Переконатися, що немає ПД, реальних службових матеріалів і секретів.
2. Ранні та проміжні скриншоти до редизайну й актуальні екрани: каталог, брифінг, рішення, підсумок, кімната з анонімними голосами, конструктор. Для кожного вказати дату, коміт, мову, тему й ширину.
3. Витяги з ітерацій: проблема → рішення → перевірка; зберегти суттєві виправлення права й обмеження, а не лише успішні кадри.
4. Підтвердження людського перегляду та окремої експертизи ДЗПК, якщо вона відбудеться. Не додавати підписи або імена без належної підстави.
5. Фактичний протокол хронометражу для заміни модельних припущень.

Рекомендовані підкаталоги після отримання матеріалів: `drafts/`, `screenshots/`, `iterations/`, `reviews/`. Вони ще не містять поданих доказів. Автоматичні знімки в `test-results/` поза Git не є архівом процесу: команда має вибрати й перенести знеособлені матеріали сюди, додавши пояснення. Не копіювати `server/data/`, cookies, `hostSecret` чи сесійні токени.

## Головний екран

Перед подачею додати `docs/process/main-screen.png`: справжній знеособлений скриншот головного екрана, на який посилається README. Поки файл відсутній, місце для зображення залишається незаповненим.

Команді потрібно додати `main-screen.png` у цю папку для зображення головного екрана в README.
