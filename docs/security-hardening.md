# Захист застосунку

Технічні запобіжники й межі наведено в [аналізі зловживань](abuse-and-safeguards.md). Сервер перевіряє Origin, hostSecret, формати й розміри запитів; застосовує CSP, scrypt, підписані сесії та обмеження частоти. Статична видача обмежена клієнтською збіркою. Для відкритого доступу потрібен HTTPS. Автотести не є незалежним аудитом безпеки.
