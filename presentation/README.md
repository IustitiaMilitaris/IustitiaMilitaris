# Презентація для фіналу

Матеріали ще не додано. Строк підготовки за вимогами подачі: **26 листопада 2026 року, 18:00 за Києвом**.

Команді потрібно додати фінальний файл презентації та перевірити посилання з кореневого README. Пропонована послідовність: проблема й аудиторія → демонстрація трьох задач → три незалежні шкали → груповий QR-режим → інтеграція SCORM/LAN → запобіжники та чесні обмеження → результати перевірок і план пілоту.

Відео до трьох хвилин і макети за наявності потребують окремих посилань. Не заявляти про проведений пілот, підтверджену економію часу, інтеграцію xAPI чи завершене правове рев’ю без відповідних доказів. [Матеріали для журі](../README.md).
